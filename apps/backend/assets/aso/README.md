# Ресурсы оформления записки

Каталог содержит шрифты Inter и Manrope, знак AIST и контрольные суммы ресурсов. Тексты лицензий шрифтов находятся рядом с файлами. Интерфейс использует SVG в `apps/web/public/aist.svg` от корня репозитория.

Dockerfile устанавливает шрифты в `/usr/local/share/fonts/aist`. Renderer проверяет их целостность, встраивает шрифты в DOCX и проверяет фактически встроенные шрифты PDF.

Pages не использует встроенные шрифты DOCX: для точного отображения на Mac нужно установить Inter и Manrope из этого каталога и открыть документ после перезапуска Pages. Обратный экспорт из Pages в DOCX может менять имена шрифтов и вызывать подстановку в LibreOffice.
