# AIST: рабочее место аналитика

Веб-приложение для подготовки аналитических записок по документам компании. Объединяет PDF-источники, чат, извлечение показателей, исследование, редактор и выпуск Word/PDF с сохранением оснований и истории версий.

Автор: Юсупов Артур Альбертович. Проект для промежуточной аттестации в МФТИ.

## Возможности

- Проекты и чаты с выбором документов для задачи.
- Извлечение текста, таблиц и визуальных данных; факты со ссылками на источники.
- Подготовка записки, поиск дополнительной информации и редакторские правки.
- История версий, выпуск DOCX/PDF, проверка доступа и учет расходов на модель.

## Устройство проекта

React и TypeScript отвечают за интерфейс. FastAPI и worker используют общий Python backend; данные хранятся в PostgreSQL и файловом хранилище. OpenClaw выполняет модельные шаги через инструменты AIST. Правами, версиями, расчетами и учетом управляет приложение.

| Каталог | Содержимое |
| --- | --- |
| `apps/backend`, `apps/web` | Backend, интерфейс и тесты |
| `executor/openclaw` | Интеграция исполнителя, инструменты и навыки |
| `contracts/v1` | Схемы данных, HTTP API и контракты инструментов |
| `infra`, `scripts` | Сборка, миграции и проверочные сценарии |

Подробнее: [архитектура](docs/architecture.md) и [контракты](contracts/v1/CONTRACT.md).

## Сборка и проверка

[Инструкция проверки](docs/testing.md) содержит команды Docker для сборки и тестирования, включая сквозной сценарий до сохранения и выпуска DOCX/PDF. Нужны Docker с Compose v2, интернет для загрузки зависимостей и поддержка Linux amd64. Проверки выполняются в изолированной сети на синтетических данных, без API-ключей и платных вызовов.

Для работы через интерфейс со своим OpenAI API-ключом: [локальное развертывание](docs/deployment.md), включая создание логина и настройку бюджета. Технические тесты не подтверждают достоверность каждого вывода модели.

Комплект рассчитан на одну локальную учебную установку с новой БД. Инструкция описывает ручное холодное копирование БД, источников, выпусков и состояния исполнителя.
